הבוט של AssistantLabs מסייע לכם להוסיף אוטומטית לידים מהוואטסאפ לרשימת התפוצה שלכם – בלי לגעת בקוד.

במדריך המצולם תראו איך לחבר את הבוט ל־שלח מסר בלי ידע טכני, בלי קוד – תוך פחות מדקה!

מתאים לעסקים, מטפלים, סדנאות, הרצאות ועוד

סנכרון אוטומטי של לידים מהבוט לרשימה שלכם

חינם להתנסות – לא צריך כרטיס אשראי

צפו במדריך כאן:

[צפייה בסרטון ההדרכה](https://www.youtube.com/embed/OtHBEmgRh2I?feature=oembed)

## **שלב 1: כניסה למערכת**

הזינו את כתובת האתר שלכם ואת מספר הטלפון. בעת הכניסה הראשונית, המערכת תסרוק את האתר ותקים בוט ראשוני עבורכם.

מומלץ להפריד בין המספר הפרטי שלכם למספר עסקי. במידה ואין לכם 2 קווים נפרדים, תוכלו לרכוש דרכנו מספר וירטואלי שתוכלו לחבר לוואטסאפ העסקי ולהמשיך להשתמש בוואטסאפ העסקי בנפרד מהוואטסאפ האישי.

לנוחיותכם [מדריך להגדרת מספר וירטואלי לוואטסאפ העסקי](https://www.sendmsg.co.il/%d7%a9%d7%9c%d7%97-%d7%9e%d7%a1%d7%a8-%d7%94%d7%92%d7%93%d7%a8%d7%aa-%d7%9e%d7%a1%d7%a4%d7%a8-%d7%95%d7%99%d7%a8%d7%98%d7%95%d7%90%d7%9c%d7%99-%d7%9c%d7%95%d7%95%d7%90%d7%98%d7%a1%d7%90%d7%a4-%d7%a2/).

## **שלב 4: הזנת פרטי החיבור**

הזינו את מספר החשבון (SiteID) וסיסמת API של שלח מסר בחלונית שנפתחת. ניתן למצוא את הפרטים בפאנל הניהול תחת ["הגדרות" > "חיבור למערכות"](https://panel.sendmsg.co.il/externalSystems.aspx?cat=4&sub=241). לאחר מכן לחצו על שמירה.

![](/kb-images/%D7%9E%D7%93%D7%A8%D7%99%D7%9A-%D7%97%D7%99%D7%91%D7%95%D7%A8-%D7%A2%D7%95%D7%96%D7%A8-%D7%97%D7%9B%D7%9D-%D7%A9%D7%9C-assistantlabs%F0%9F%9A%80/05.jpeg)

בחרו את רשימת התפוצה אליה יתוספו הלידים מהבוט, ולחצו שוב על שמירה. לאחר השמירה תיפתח רשימה, בחרו את רשימת הדיוור הרצויה.

## שאלות נפוצות

**אילו דרישות מקדימות נדרשות לחיבור שלח מסר לבוט וואטסאפ AI?**נדרש חשבון פעיל במערכת הבוט ופרטי API של שלח מסר (SiteID וסיסמת API). בנוסף מומלץ להשתמש במספר וואטסאפ עסקי נפרד מהמספר הפרטי.

**כיצד מחברים את הבוט לשלח מסר?**נכנסים להגדרות הבוט > אינטגרציות > הוסף אינטגרציה ובוחרים בשלח מסר. מזינים SiteID וסיסמת API, שומרים ובוחרים את רשימת התפוצה הרצויה.

**היכן מוצאים את פרטי ה-API של שלח מסר?**יש להיכנס למערכת שלח מסר תחת "הגדרות" > "חיבור למערכות". שם מופיעים מספר החשבון (SiteID) וסיסמת ה-API הנדרשת לחיבור.

**כיצד בודקים שהאינטגרציה פועלת תקין?**יש לוודא שהאינטגרציה מופיעה ברשימת האינטגרציות הפעילות. לאחר מכן ניתן לשלוח הודעה לבוט ולבדוק שהליד נוסף אוטומטית לרשימת הדיוור במערכת.

**מה לעשות במקרה של תקלה בחיבור?**יש לוודא שהוזנו פרטי API נכונים ושרשימת התפוצה נבחרה ונשמרה. במידת הצורך ניתן לפנות לתמיכה של AssistantLabs לסיוע טכני.

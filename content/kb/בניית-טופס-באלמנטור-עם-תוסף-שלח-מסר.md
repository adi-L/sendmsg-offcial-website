המדריך זה נציג לכם כיצד ניתן לחבר את הטופס שבניתם באלמנטור PRO באמצעות התוסף החדש של שלח מסר

### [**לצפייה בסרטון הדרכה**](https://www.sendmsg.co.il/%d7%91%d7%a0%d7%99%d7%99%d7%aa-%d7%98%d7%95%d7%a4%d7%a1-%d7%91%d7%90%d7%9c%d7%9e%d7%a0%d7%98%d7%95%d7%a8-%d7%a2%d7%9d-%d7%aa%d7%95%d7%a1%d7%a3-%d7%a9%d7%9c%d7%97-%d7%9e%d7%a1%d7%a8/#video)

## שלב ראשון הגדרת שדות במערכת שלח מסר:

**על מנת לעבוד עם טפסים באלמנטור, יש לעבוד על אלמנטור Pro.**

לאחר שבניתם את הטופס שלכם באלמנטור, יש לוודא כי אותם שדות אשר קיימים בטופס קיימים גם בחשבונכם בשלח מסר.

1. יש ללכת ל**הגדרות**> **כלים**> **הגדרת שדות**:

באזור זה יש לעבור על הרשימה של השדות ולוודא שהשדות שהשתמשתם בהם בטופס מופיעים, במידה והם אינם ברשימה יש להוסיף אותם במערכת.

## שלב שני- הוספת התוסף של שלח מסר באלמנטור:

1. יש להיכנס לחשבונכם ב**אלמנטור** ובתפריט השמאלי יש לבחור תחת לשונית "**תוספים**"> **הוסף חדש:**

![](/kb-images/%D7%91%D7%A0%D7%99%D7%99%D7%AA-%D7%98%D7%95%D7%A4%D7%A1-%D7%91%D7%90%D7%9C%D7%9E%D7%A0%D7%98%D7%95%D7%A8-%D7%A2%D7%9D-%D7%AA%D7%95%D7%A1%D7%A3-%D7%A9%D7%9C%D7%97-%D7%9E%D7%A1%D7%A8/02.png)

2. לאחר מכן, יש להזין בשורת החיפוש "שלח מסר" או באנגלית **sendmsg.**

שם התוסף שיש להתקין :**Sendmsg Elementor Addon**

![](/kb-images/%D7%91%D7%A0%D7%99%D7%99%D7%AA-%D7%98%D7%95%D7%A4%D7%A1-%D7%91%D7%90%D7%9C%D7%9E%D7%A0%D7%98%D7%95%D7%A8-%D7%A2%D7%9D-%D7%AA%D7%95%D7%A1%D7%A3-%D7%A9%D7%9C%D7%97-%D7%9E%D7%A1%D7%A8/03.png)

3. לאחר שהסתיימה התקנת התוסף> יש ללחוץ על **"הפעלה**":

![](/kb-images/%D7%91%D7%A0%D7%99%D7%99%D7%AA-%D7%98%D7%95%D7%A4%D7%A1-%D7%91%D7%90%D7%9C%D7%9E%D7%A0%D7%98%D7%95%D7%A8-%D7%A2%D7%9D-%D7%AA%D7%95%D7%A1%D7%A3-%D7%A9%D7%9C%D7%97-%D7%9E%D7%A1%D7%A8/04.png)

4. כעת יש לחבר את התוסף באמצעות**API** באלמנטור:

ראשית, יש להיכנס להוציא את פרטי הAPI מחשבונכם בשלח מסר:

**פרטי הגישה לחשבון (שם משתמש + API Password) יופיעו בתוך מערכת שלח מסר:**

**כנסו ל "הגדרות"> חיבור למערכות:**

![](/kb-images/%D7%91%D7%A0%D7%99%D7%99%D7%AA-%D7%98%D7%95%D7%A4%D7%A1-%D7%91%D7%90%D7%9C%D7%9E%D7%A0%D7%98%D7%95%D7%A8-%D7%A2%D7%9D-%D7%AA%D7%95%D7%A1%D7%A3-%D7%A9%D7%9C%D7%97-%D7%9E%D7%A1%D7%A8/05.png)

יופיעו לכם פרטי חשבון ה- API שלכם :

ובמידה וסיסמא אינה מופיעה בחלון הרצוי, סימן שטרם נוצרה וניתן לייצר סיסמא חדשה.

![](/kb-images/%D7%91%D7%A0%D7%99%D7%99%D7%AA-%D7%98%D7%95%D7%A4%D7%A1-%D7%91%D7%90%D7%9C%D7%9E%D7%A0%D7%98%D7%95%D7%A8-%D7%A2%D7%9D-%D7%AA%D7%95%D7%A1%D7%A3-%D7%A9%D7%9C%D7%97-%D7%9E%D7%A1%D7%A8/06.png)

5. כעת שיש לכם את פרטי הAPI, יש לחזור **לאלמנטור**ולהיכנס ללשונית **הגדרות**> **sendmsg API:**

6. בחלונית במרכז המסך, יש להזין את פרטי הAPI שלכם:

## שלב שלישי – הגדרות טופס באלמנטור וחיבור לשלח מסר:

1. יש לבחור בתפריט השמאלי בלשונית **"עמודים".**באזור זה ניתן להיכנס לעריכת דף נחיתה קיים, או ליצור דף נחיתה חדש.

![](/kb-images/%D7%91%D7%A0%D7%99%D7%99%D7%AA-%D7%98%D7%95%D7%A4%D7%A1-%D7%91%D7%90%D7%9C%D7%9E%D7%A0%D7%98%D7%95%D7%A8-%D7%A2%D7%9D-%D7%AA%D7%95%D7%A1%D7%A3-%D7%A9%D7%9C%D7%97-%D7%9E%D7%A1%D7%A8/10.png)

2. בתוך דף הנחיתה באלמנטור, יש להוסיף את בלוק **טופס** ההרשמה:

![](/kb-images/%D7%91%D7%A0%D7%99%D7%99%D7%AA-%D7%98%D7%95%D7%A4%D7%A1-%D7%91%D7%90%D7%9C%D7%9E%D7%A0%D7%98%D7%95%D7%A8-%D7%A2%D7%9D-%D7%AA%D7%95%D7%A1%D7%A3-%D7%A9%D7%9C%D7%97-%D7%9E%D7%A1%D7%A8/11.png)

3. לאחר מכן, בחרו את השדות שתרצו שיופיעו בטופס מתוך התפריט הימני:

![](/kb-images/%D7%91%D7%A0%D7%99%D7%99%D7%AA-%D7%98%D7%95%D7%A4%D7%A1-%D7%91%D7%90%D7%9C%D7%9E%D7%A0%D7%98%D7%95%D7%A8-%D7%A2%D7%9D-%D7%AA%D7%95%D7%A1%D7%A3-%D7%A9%D7%9C%D7%97-%D7%9E%D7%A1%D7%A8/12.png)

לסיום הגדרת הטופס יש ללחוץ על "**עדכן**" בתחתית התפריט.

4. לאחר שסיימתם להוסיף את השדות לטופס, יש ללכת ללשונית "**פעולות אחרי שליחה**" בתפריט הימני,

על מנת לחבר בין הטופס למערכת שלח מסר:

![](/kb-images/%D7%91%D7%A0%D7%99%D7%99%D7%AA-%D7%98%D7%95%D7%A4%D7%A1-%D7%91%D7%90%D7%9C%D7%9E%D7%A0%D7%98%D7%95%D7%A8-%D7%A2%D7%9D-%D7%AA%D7%95%D7%A1%D7%A3-%D7%A9%D7%9C%D7%97-%D7%9E%D7%A1%D7%A8/13.png)

6. תחת פעולות אחרי שליחה, יש לפתוח את הלשונית של **"הוספת פעולה**", ולבחור מתוך הרשימה את **sendmsg**:

![](/kb-images/%D7%91%D7%A0%D7%99%D7%99%D7%AA-%D7%98%D7%95%D7%A4%D7%A1-%D7%91%D7%90%D7%9C%D7%9E%D7%A0%D7%98%D7%95%D7%A8-%D7%A2%D7%9D-%D7%AA%D7%95%D7%A1%D7%A3-%D7%A9%D7%9C%D7%97-%D7%9E%D7%A1%D7%A8/14.png)

7. אחרי שבחרתם בsendmsg> הוא נוסף בתור קטגוריה בתפריט הימני, יש לפתוח את הקטגוריה בכדי להיכנס ולהגדיר את הנתונים הבאים:

**קבוצת הדיוור-** כעת יש לבחור את קבוצת הדיוור הקיימת בחשבונכם בשלח מסר, אליה תרצו שהלידים יכנסו לאחר ההרשמה בטופס. ניתן לפתוח את החלונית ולבחור מתוך הרשימה של קבוצות הדיוור:

![](/kb-images/%D7%91%D7%A0%D7%99%D7%99%D7%AA-%D7%98%D7%95%D7%A4%D7%A1-%D7%91%D7%90%D7%9C%D7%9E%D7%A0%D7%98%D7%95%D7%A8-%D7%A2%D7%9D-%D7%AA%D7%95%D7%A1%D7%A3-%D7%A9%D7%9C%D7%97-%D7%9E%D7%A1%D7%A8/15.png)

**התאמת שדות-**יש להתאים את השדות בתפריט, לפי השדות שבחרתם בטופס:

למשל, אם בחרנו שיופיע שדה **אימייל**בטופס, בתפריט הימני לצד שדה "**אימייל**" נעביר את הערך במקום "**None**" ל- "**email**", כפי שמופיע בתמונה מטה:

![](/kb-images/%D7%91%D7%A0%D7%99%D7%99%D7%AA-%D7%98%D7%95%D7%A4%D7%A1-%D7%91%D7%90%D7%9C%D7%9E%D7%A0%D7%98%D7%95%D7%A8-%D7%A2%D7%9D-%D7%AA%D7%95%D7%A1%D7%A3-%D7%A9%D7%9C%D7%97-%D7%9E%D7%A1%D7%A8/16.png)

לסיום יש ללחוץ על "**עדכן**".

לאחר סיימתם לחבר את הטופס באלמנטור באמצעות התוסף של שלח מסר, יש לבצע בדיקה.

פתחו את הלינק של הדף בלשונית דפדפן חדשה ורישמו את עצמכם ובידקו הם כאשר נרשמתם הנתונים שהזנתם נכנסו גם למערכת שלח מסר.

## שאלות נפוצות

**אילו דרישות מקדימות יש לחיבור טופס אלמנטור לשלח מסר?**נדרש להשתמש ב-Elementor Pro ולהתקין את התוסף Sendmsg Elementor Addon. בנוסף יש לוודא שכל השדות הקיימים בטופס מוגדרים גם במערכת שלח מסר תחת "הגדרת שדות".

**כיצד מחברים את אלמנטור לשלח מסר באמצעות API?**יש להוציא פרטי API מתוך שלח מסר (הגדרות > חיבור למערכות) ולהזין אותם באלמנטור תחת sendmsg API. לאחר הזנת שם משתמש וסיסמת API לוחצים על Connect Now ומוודאים שהחיבור הצליח.

**כיצד מגדירים שטופס ישלח לידים לקבוצת דיוור?**בטופס באלמנטור יש להוסיף פעולה אחרי שליחה מסוג sendmsg. לאחר מכן בוחרים קבוצת דיוור ומתאימים בין שדות הטופס לשדות במערכת.

**מהי תקלה נפוצה בחיבור טופס לאלמנטור?**אי התאמה בין שדות הטופס לשדות הקיימים בשלח מסר עלולה למנוע קליטת נתונים. יש לוודא שכל שדה קיים במערכת ושבוצעה התאמה נכונה תחת מיפוי השדות.

**כיצד בודקים שהחיבור פועל תקין?**יש לפתוח את דף הנחיתה בדפדפן, לבצע הרשמה ניסיונית, ולבדוק שהנתונים נקלטו בקבוצת הדיוור במערכת. בדיקה זו מאשרת שה-API וההתאמות הוגדרו כראוי.
